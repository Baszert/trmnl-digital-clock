# Digital Clock

The feeling of an 80's/90's digital clock: time and date in a retro 14-segment display. And a clock that is never on time, every time.

<a href="https://trmnl.com/recipes/190574"><img width="150" alt="Works with TRMNL" src="https://trmnl.com/images/brand/badges/light/works-with-trmnl/trmnl-badge-works-with-light.svg" /></a>

## Settings
- **Location:** optional name shown under the clock
- **Time format:** 24h or 12h (AM/PM)
- **Date format:** DD MMM YYYY or MMM DD, YYYY
- **Color mode:** dark or light

Uses your TRMNL account timezone. No external data.

### Develop locally

Templates and settings live in [`src/`](src/), ready for [trmnlp](https://github.com/usetrmnl/trmnlp):

```sh
gem install trmnl_preview
trmnlp serve
```
